# Weakpoint Lock-On (HellForge gameplay mod)

**Version 3.0.0.** A fixed set of lock-on changes for HellForge that move the lock-on point of many enemies and structures to a weak point (heads, joints, fabricator frames), so lock-on weapons aim there. Sentries, Arc weapons and flamethrowers aim through the same point, so they follow it too.

Built to work in tandem with [Hellforge Rebalanced](https://github.com/Telair-JC/hellforge-rebalanced).

## Download

Get `weakpoint-lockon-3.0.0.zip` from [Releases](../../releases).

## Install

Put the `weakpoint-lockon` folder from the zip in `<HellForge>\mods`, switch it on on the Mods page, and play. Disable the original package if it is also installed.

To change which options are included, use the original package's mod-manager version instead, or ask for a rebuild.

## How this differs from the original

The original is a pack of optional lock-on changes for the live game, installed through a mod manager, where each option is switched on or off on its own. This version ships a fixed set of the options as one HellForge data mod flagged as a **gameplay** mod, for the purpose of game balance and mod sharing in Helldivers multiplayer: HellForge compares gameplay mods between the players in a lobby, so everyone in the lobby runs the same lock-on points and the join is refused when the files differ. The patch data itself is unchanged and is repackaged as the original author made it.

## Included options

- **Terminids:** Hunter, Warrior, Hive Guard (head), Commander (head), Spewer, Stalker, Charger (head), Impaler, Titan, Dragonroach
- **Automatons:** Trooper, Berserker, Devastator, Hulk, War Strider (left hip joint), Factory Strider, Radical / Agitator
- **Illuminate:** Voteless, Overseer, Harvester (right leg joint), Wretch (head), Crusher
- **Structures:** Bot Fabricator, Bulk Fabricator, Command Bunker corners, Spore Thrower, Shrieker Nest

**Left out:** the "Disable Lockon" options, and the Charger leg / War Strider eye / Harvester eye options. Scout Strider keeps the game's own lock-on (no patch).
